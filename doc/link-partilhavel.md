# Alojamento Gratuito na Nuvem (HuggingFace Spaces)

1. Crie uma conta gratuita em [huggingface.co](https://huggingface.co/).
2. Crie um novo **Space** e selecione a opção **Docker** ou **Python / Streamlit/FastAPI**.
3. Envie os ficheiros do seu projeto (`server.py`, `requirements.txt`, pasta `static/`).
4. O Hugging Face gera automaticamente um link partilhável como:
   `https://huggingface.co/spaces/seu-usuario/gp-training-app`
